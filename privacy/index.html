Privacy Policy for Jamie

Last updated: November 23, 2026

Jamie is a personal AI agent built and used only by Vishwa Mehta to manage her own job search. It is not offered to the public, and no one other than Vishwa signs in to it.

Google user data Jamie accesses

Jamie connects only to Vishwa's own Gmail account (vishwamehta1011@gmail.com) and requests two permissions:

  • Send email (gmail.send): to send outreach emails that Vishwa wrote, from her own account.
  • Read email (gmail.readonly): only to find delivery failure notices (bounces) for those emails, so Jamie stops writing to addresses that do not work.

How the data is used and stored

  • Jamie stores only what it needs: the recipient, subject, send time, Gmail message and thread IDs, and whether a message bounced. It does not store the contents of other emails in the inbox.
  • Data is kept in Vishwa's private database and is used only to run her own outreach.
  • Google user data is never sold, never shared with third parties, never used for advertising, and never used to train AI models.
  • Jamie's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access and deleting data

Access can be removed at any time from the Google Account page under Security, Third-party apps and services. To ask for any stored data to be deleted, email the address below.
